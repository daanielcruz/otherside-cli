# otherside

Rust reimplementation of a Claude-Code-flavored interactive coding agent with multi-provider backends (anthropic-oauth, codex, gemini-cli, openai-compatible).

**Status:** planning + scaffold. No binary yet.

## Where to start

- `openspec/project.md` — one-page project context (Claude sessions, start here)
- `docs/README.md` — docs index (human-readable)
- `openspec/changes/` — in-flight changes with proposals and task checklists

While otherside lives inside the `claude-code/` repo, Claude sessions also pick up the parent `claude-code/CLAUDE.md` "otherside cli" section. A dedicated `OTHERSIDE.md` will be created at v1 graduation when the folder moves out.
